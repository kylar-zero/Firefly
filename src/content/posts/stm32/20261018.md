### STM32 型号解析：C8T6

| 字段 | 代表含义 | 常用型号解析（以 C8T6 为例） |
| :---: | :--- | :--- |
| **C** | 引脚数量 (Pin) | **C = 48 引脚**<br>(T=36, R=64, V=100, Z=144) |
| **8** | Flash 容量 | **8 = 64 Kbytes**<br>(6=32K, B=128K, C=256K) |
| **T** | 封装类型 | **T = LQFP** (方形贴片)<br>(H=BGA, I=UFBGA, U=VFQFPN) |
| **6** | 温度范围 | **6 = -40 ~ 85℃** (工业级)<br>(7 = -40 ~ 105℃) |

### IO引脚最大输出速度
**IO最大输出速度**：向IO交替写0和1且输出不失真的最快速度（波形不能正常输出）

![理想与实际](image-8.png)

即**上升时间**和**下降时间**限制了最大输出速度。**上升时间**/**下降时间**越短越大。

![速度选择](image-9.png)

选取满足要求的最小值，过于陡峭会**增加耗电**，引入**EMI问题**，即对其他元器件造成电磁波干扰。
人眼**45.8HZ**。**8 Mbit/s**（某些时候可看做波特率） 等于 **8 MHz（8兆赫兹）**。在单片机只传 0 和 1 的情况下，**12 Mbps** 等同于 **12 MBaud**（波特率）。

**注意一个大坑：bit 和 Byte 的区别！**

这是新手最容易看错的地方，一定要小心大小写的 b：
1.小写 b：Mbps（Megabit per second）= 兆比特/秒。
2.大写 B：MBps（MegaByte per second）= 兆字节/秒。
3.换算关系：1 Byte（字节） = 8 bit（比特）。

所以，12 Mbps 的实际数据量是：
**12 ÷ 8 = 1.5 MB/s（兆字节每秒）。**

### LED闪灯实验
![推挽与开漏](image-10.png)

![GPIO模块编程接口](image-11.png)

![GPIO_Init编程设置](image-12.png)

![延迟设置](image-14.png)

```c
#include "stm32f10x.h"
#include "delay.h"

int main(void)
{
	// #1. 开启GPIOC的时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
	
	// #2. 初始化IO引脚，PC13 通用输出开漏模式 2MHz
	GPIO_InitTypeDef GPIO_InitStruct = {0};
	
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_13;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_OD;
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_2MHz;
	
	GPIO_Init(GPIOC, &GPIO_InitStruct);
	
	// GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_SET);   // 写1
	// GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_RESET); // 写0
	
	while(1)
	{
		GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_RESET); // 亮
		Delay_ms(100);                                // 延迟100ms
		
		GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_SET);   // 灭
		Delay_ms(100);                                // 延迟100ms
	}
}
```
**实验注意：需要按一下复位按钮。**

### 纽扣实验

**LED灯长边是阳极**
```c
#include "stm32f10x.h"//推挽接法

int main(void)
{
	// 开启GPIOA的时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
	
	// 定义结构体变量
	GPIO_InitTypeDef GPIO_InitStruct;
	
	// 配置 PA0 引脚
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_0;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_PP;   // 推挽输出
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_2MHz;   // 速度 2MHz
	
	// 初始化 GPIOA
	GPIO_Init(GPIOA, &GPIO_InitStruct);
	
	// 直接将 PA0 置为高电平（输出 3.3V）
	GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);
}
```
![按钮结构图](image-17.png)

![电路图](image-18.png)

![GPIO_ReadInputDataBit编程设置](image-20.png)

```c
#include "stm32f10x.h"

int main(void)
{
	// 1. 开启 GPIOA 的时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
	
	// 2. 初始化 PA0 (LED输出引脚)
	GPIO_InitTypeDef GPIO_InitStruct;
	
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_0;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_Out_PP;  // 推挽输出
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_2MHz;
	GPIO_Init(GPIOA, &GPIO_InitStruct);
	
	// 3. 初始化 PA1 (按键输入引脚)
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_1;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;     // 上拉输入 (Internal Pull-Up)
	GPIO_Init(GPIOA, &GPIO_InitStruct);
	
	// 进入主循环
	while(1)
	{
		// 读取 PA1 的电平，如果等于 0 (按下按键)
		if(GPIO_ReadInputDataBit(GPIOA, GPIO_Pin_1) == Bit_RESET)
		{
			// 点亮 PA0 上的 LED (输出低电平)
			GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);
		}
		else // 如果 PA1 是高电平 (松开按键)
		{
			// 熄灭 PA0 上的 LED (输出高电平)
			GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);
		}
	}
}
```

**波特率：每秒钟最多传输多少位**（常用波特率9600、115200、921600）

![设置波特率，填入X在波特率寄存器](image-29.png)

![USART_Init编程设置](image-30.png)

```c
#include "stm32f10x.h"

int main(void)
{
	// 开启 USART1 的时钟（USART1 挂载在 APB2 总线上）
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);
	
	// 定义串口初始化结构体
	USART_InitTypeDef USART_InitStruct;
	
	// 配置串口参数
	USART_InitStruct.USART_BaudRate = 115200;                         // 波特率：115200
	USART_InitStruct.USART_Mode = USART_Mode_Tx | USART_Mode_Rx;      // 模式：同时开启发送(Tx)和接收(Rx)
	USART_InitStruct.USART_WordLength = USART_WordLength_8b;          // 数据位：8位
	USART_InitStruct.USART_StopBits = USART_StopBits_1;               // 停止位：1位
	USART_InitStruct.USART_Parity = USART_Parity_No;                  // 校验位：无
	
	// 将配置写入 USART1 寄存器
	USART_Init(USART1, &USART_InitStruct);
	
}
```

**默认位置**（*PA9 PA10*）
```c
#include "stm32f10x.h"

int main(void)
{
	// 1. 开启 USART1 时
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_USART1, ENABLE);
	
	// 2. 配置串口参数 (115200-8-N-1)
	USART_InitTypeDef USART_InitStruct;
	USART_InitStruct.USART_BaudRate = 115200;
	USART_InitStruct.USART_Mode = USART_Mode_Tx | USART_Mode_Rx;
	USART_InitStruct.USART_WordLength = USART_WordLength_8b;
	USART_InitStruct.USART_StopBits = USART_StopBits_1;
	USART_InitStruct.USART_Parity = USART_Parity_No;
	
	USART_Init(USART1, &USART_InitStruct);
	
	// 3. 配置 GPIO 引脚 (PA9=TX, PA10=RX)
	GPIO_InitTypeDef GPIO_InitStruct;
	
	// 开启 GPIOA 时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
	
	// 配置 PA9 (TX 发送引脚)
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_9;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_AF_PP;     // 复用推挽输出
	GPIO_InitStruct.GPIO_Speed = GPIO_Speed_10MHz;   // 注意：这里教程选了 10MHz
	GPIO_Init(GPIOA, &GPIO_InitStruct);
	
	// 配置 PA10 (RX 接收引脚)
	GPIO_InitStruct.GPIO_Pin = GPIO_Pin_10;
	GPIO_InitStruct.GPIO_Mode = GPIO_Mode_IPU;       // 上拉输入
	GPIO_Init(GPIOA, &GPIO_InitStruct);
	
}
```
